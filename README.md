# Adaptive AI-Driven NIDS — Specification Pack

This repository contains the architecture and interface contracts for an offline-first AI-driven network intrusion detection and investigation platform.

## Documents
- `PROJECT_SPEC.md` — scope, architecture, folder structure, modules, roles, workflows, testing.
- `docs/API_CONTRACT.md` — endpoints, request/response shapes, errors, status codes, auth, enums.
- `docs/DATABASE_SCHEMA.md` — MongoDB collections, indexes, validation, pagination, retention.
- `docs/ML_CONTRACT.md` — feature schema, prediction contract, scoring, evaluation, model lifecycle.
- `docs/SAFETY_POLICY.md` — prohibited operations, passive/offline behavior, simulated response, security.
- `docs/INTEGRATION_GUIDE.md` — setup, startup order, agent ownership, integration sequence, acceptance criteria.

These documents specify intended behavior. They do not claim the application has been implemented or that a model has demonstrated any particular detection performance.
